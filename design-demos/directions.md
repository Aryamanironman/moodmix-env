# Six direction candidates

S = 57. Web roulette = 57 % 20 + 1 = 18 (Gallery Dark). East roulette =
57 % 12 + 1 = 10 (Hattori Playful Offset). Ledger: the last project used a
light cool #EEF1F4 page with ui-sans-serif headings; none of these reuse it.

## 1. Best designer - Teenage Engineering instrument

- Source: Teenage Engineering TX-6 and OP-1 field design language. Reference
  board `refs/te.jpg`; secondary Pioneer hardware `refs/dj-interfaces-1.jpg`.
- Borrowed rules: CNC aluminum slab, rows of identical knobs and faders, a
  tiny OLED, green LED ladders, color-coded channel labels, product staged on
  black. Controls are the layout, not decoration.
- Main material: procedural brushed aluminum, SVG/CSS knobs, faders and LEDs.
  No photography.
- Skeleton: full-width hardware console. Two deck strips flank a central
  mixer, the crate is a pull-out drawer, the transition scope runs along the
  bottom.
- Boldness: the whole page is the instrument. No dashboard cards.
- Form from content: the crossfader and EQ knobs are the actual transition
  controls; the performance is physical.

## 2. Best designer - David Carson / Ray Gun deconstruction

- Source: David Carson's Ray Gun magazine language (1990s). This is a
  designer reference, not a product reference.
- Borrowed rules: broken grid, overlapping and rotated display type, type as
  image, photocopy grain, aggressive scale jumps, no polite header.
- Main material: type, a cut-out waveform, halftone and overprint stripes.
- Skeleton: a rave flyer. Giant track names collide over a waveform strip, a
  printed tracklist runs down one side, the controls are a small booth strip
  at the bottom.
- Boldness: typographic collision, used once.
- Form from content: a flyer announcing the blend.

## 3. Reality - Pioneer DJ CDJ-3000 / DJM club hardware

- Source: verified official CDJ-3000 page, reference board
  `refs/dj-interfaces-1.jpg`.
- Borrowed rules: jog wheel with concentric rings, channel strips, vertical
  VU meters, cue and play LEDs, small LCD readouts, orange accents on dark
  metal.
- Main material: procedural hardware, SVG platters and meters.
- Skeleton: a club booth, two players and a mixer, the crate behind the
  booth.
- Boldness: the booth is the page.
- Form from content: actual club hardware logic, not a generic control panel.

## 4. Reality - Traktor Pro 4 software performance view

- Source: verified official Traktor Pro 4 page, reference board
  `refs/dj-interfaces-2.jpg`.
- Borrowed rules: stacked scrolling waveforms with beat grids, deck headers,
  central mixer strip, dense dark UI, browser at the bottom, FX/loop panels.
- Main material: canvas/SVG waveforms generated from the real transition
  data.
- Skeleton: waveform-first performance screen: deck A waveform, deck B
  waveform, mixer, browser, analysis.
- Boldness: the waveform is the hero, not a chart card.
- Form from content: DJ software for a live transition, not a dashboard.

## 5. Roulette web #18 - Gallery Dark

- Source: `assets/style-specimens/web/18-gallery-dark.jpg` (Gallery Dark).
- Borrowed rules: near-black, one large object centered, tiny EXIF-like
  metadata, UI almost invisible, enormous negative space.
- Main material: the transition waveform as the single artwork.
- Skeleton: a dark listening room: artwork, metadata below, a minimal
  transport, a thin index.
- Boldness: removing the interface.
- Form from content: a dark gallery for one mix.

## 6. Roulette east #10 - Hattori Playful Offset

- Source: `assets/style-specimens/east/10-hattori-playful-offset.jpg`
  (Hattori Playful Offset), secondary David Carson.
- Borrowed rules: a giant numeral filled with offset red/blue stripes, a
  tilted yellow block, a black block, a red circle, a hand-drawn wave, a
  matter-of-fact info table, off-white paper.
- Main material: type, CSS stripe fills, SVG wave, printed blocks.
- Skeleton: a printed rave scorecard. The score 14.98 is the monument, track
  names and cue data are blocks, the tracklist is liner notes, the controls
  are a printed booth strip.
- Boldness: the score as a striped monumental numeral.
- Form from content: a printed scorecard for the mix.

## Chosen full directions

- A: #1 hardware instrument, with #3 as the reality check.
- B: #4 Traktor-style software performance.
- C: #6 striped print scorecard, with #2 as the deconstruction reference.
- #2, #3 and #5 remain as thumbnails and alternates.
